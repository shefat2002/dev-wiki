# Mobile Development — Getting Started

This guide helps you set up and start working on the mobile application.

## Prerequisites

- Node.js
- React Native CLI or Expo CLI
- Android Studio / Xcode

## Setup

1. Install dependencies: `npm install`
2. Start Metro bundler: `npx react-native start`
3. Run on Android: `npx react-native run-android`
4. Run on iOS: `npx react-native run-ios`
