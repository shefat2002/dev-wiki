##  How to Use This Wiki

* Browse by **category (folders)**
* Use GitHub **search (Ctrl + K)** to quickly find topics
* Follow step-by-step guides inside each document

---

##  How to Contribute

1. Fork the repository
2. Create a new branch
3. Add your guide in the correct folder
4. Follow the template from [`TEMPLATE.md`](TEMPLATE.md)
5. Update this README (if needed)
6. Submit a Pull Request

---

##  Writing Standards

* Use clear titles: `how-to-setup-docker.md`
* Keep steps **short and actionable**
* Add **code snippets**
* Add **screenshots/diagrams** when needed
* Avoid long theory  focus on **practical execution**

---

##  Example Guide Structure

```md
# Setup Docker for .NET API

##  Goal
Run a .NET API using Docker.

##  Prerequisites
- Docker installed
- .NET SDK

##  Steps
1. Create Dockerfile
2. Build image
3. Run container

##  Common Issues
- Port conflict  change port

##  References
- Official docs
```
