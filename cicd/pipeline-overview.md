# CI/CD Pipeline Overview

This document describes the continuous integration and deployment pipelines used in the project.

## Pipeline Stages

1. **Build** — Compile the application and resolve dependencies.
2. **Test** — Run automated tests.
3. **Static Analysis** — Lint and security scans.
4. **Package** — Build Docker images or deployment artifacts.
5. **Deploy** — Deploy to the target environment.

## Tools

- GitHub Actions (CI/CD)
- Docker
